# Axis Forge

A dependency-free static website for a structural detailing and BIM consultancy.

## Deploy to Vercel

Import this repository into Vercel and keep the detected settings. The committed `vercel.json` configures the project as a framework-free static site, runs the validation build, and publishes the `dist` directory.

No environment variables or server-side services are required.

## Local development

```bash
npm run dev
```

## Validate the deployment output

```bash
npm run build
```
